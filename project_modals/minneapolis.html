Extracting Records from Minneapolis City Directories

GitHub

This is a personal project I did over the summer. I created a pipeline that extracts structured resident data from scanned Minneapolis city directory pages (1900–1950). It detects the listing regions on each page, runs OCR on them, and outputs JSON so you can trace who lived at a given address across decades.

Tech & Skills

  • Python, OpenCV, PIL
  • YOLOv8 (object detection)
  • Tesseract OCR
  • LabelStudio (data annotation)
  • Image preprocessing & layout detection
